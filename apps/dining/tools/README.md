# 🎨 SVG Layout Converter Tool

## 📖 Overview

This browser-based tool transforms Figma SVGs into DropBy-compatible venue layouts with automatic bounding box calculation and database SQL generation.

---

## 🚀 How to Use

### **Step 1: Open the Tool**

1. Navigate to `tools/svg-layout-converter.html`
2. Open it in your web browser (Chrome, Firefox, Safari, Edge)
3. No installation or server needed - works 100% offline!

### **Step 2: Upload Your Figma SVG**

1. Click the upload zone or drag & drop your SVG file
2. The tool will automatically analyze the structure

### **Step 3: Review Detected Sections**

The tool will show you:
- ✅ **ViewBox**: SVG dimensions
- ✅ **Sections Found**: Number of clickable areas detected
- ✅ **Total Paths**: Visual elements count
- ✅ **File Size**: Original file size

### **Step 4: Configure Each Section**

For each detected section, you can edit:

1. **Polygon Key** (CRITICAL for database):
   - This MUST match the value you'll use in `event_layout_sections.polygon_key`
   - Examples: `STAGE`, `MVP`, `VIP`, `FANPIT`, `VVIP`
   - Use UPPERCASE for consistency

2. **Display Name**:
   - Human-readable name shown in your app
   - Examples: "Backstage Access", "MVP Lounge", "VIP Section"

3. **Bounding Box** (Auto-calculated):
   - x, y, width, height coordinates
   - Used for clickable overlay positioning
   - Automatically extracted from SVG paths

### **Step 5: Transform SVG**

Click **"✨ Transform SVG"** button

The tool will:
- ✅ Remove container groups (`Frame 2`, `Group 2`, etc.)
- ✅ Flatten section structure to root level
- ✅ Remove `width` and `height` attributes
- ✅ Add `data-id` and `class` attributes
- ✅ Add `data-bbox` attribute with coordinates
- ✅ Keep only `viewBox` for responsive scaling

### **Step 6: Get Database Configuration**

The tool shows:
1. **Polygon Keys List**: Copy these exact values for your database
2. **SQL Statements**: Ready-to-use INSERT commands

### **Step 7: Download & Deploy**

1. Click **"⬇️ Download Transformed SVG"**
2. Upload the transformed SVG to Supabase Storage:
   ```
   Bucket: event-layouts (or your bucket name)
   Path: layouts/event-{event-id}.svg
   ```
3. Get the public URL from Supabase

### **Step 8: Update Database**

1. Copy the SQL from the tool
2. Replace `'YOUR_LAYOUT_ID'` with your actual layout ID
3. Set capacities for each section
4. Run in Supabase SQL Editor

## 📋 Complete Workflow Example

### **1. Design in Figma**

```
Your Figma layers:
├── Frame 2 (container)
│   ├── STAGE (section)
│   │   └── Dj Layout (visual group)
│   ├── Group 2
│   │   └── FANPIT (section)
│   └── MVP (section)
```

### **2. Export SVG from Figma**

File → Export → SVG

### **3. Upload to Converter Tool**

Drag & drop `my-venue.svg`

### **4. Tool Shows Analysis**

```
ViewBox: 0 0 1080 1350
Sections Found: 5
- STAGE (Backstage Access)
- FANPIT (Fanpit Access)
- MVP (MVP Lounge)
- VVIP (VVIP Section)
- VIP (VIP Lounge)
```

### **5. Configure Polygon Keys**

```
STAGE    → polygon_key: "STAGE"    → Name: "Backstage Access"
FANPIT   → polygon_key: "FANPIT"   → Name: "Fanpit Access"
MVP      → polygon_key: "MVP"      → Name: "MVP Lounge"
VVIP     → polygon_key: "VVIP"     → Name: "VVIP Section"
VIP      → polygon_key: "VIP"      → Name: "VIP Lounge"
```

### **6. Transform & Download**

Result: `my-venue-transformed.svg`

### **7. Upload to Supabase**

```
Bucket: event-layouts
File: layouts/summer-fest-2025.svg
URL: https://your-project.supabase.co/storage/v1/object/public/event-layouts/layouts/summer-fest-2025.svg
```

### **8. Create Event Layout**

```sql
INSERT INTO event_layouts (
  id,
  event_id,
  svg_url,
  viewbox
) VALUES (
  gen_random_uuid(),
  'your-event-id',
  'https://your-project.supabase.co/storage/v1/object/public/event-layouts/layouts/summer-fest-2025.svg',
  '0 0 1080 1350'
) RETURNING id;
```

Copy the returned `id` - this is your `layout_id`

### **9. Insert Sections**

Use the SQL generated by the tool, replacing:
- `'YOUR_LAYOUT_ID'` → with the ID from step 8
- Capacity values → actual section capacities

```sql
INSERT INTO event_layout_sections (
  layout_id,
  polygon_key,
  name,
  bbox_x,
  bbox_y,
  bbox_width,
  bbox_height,
  capacity_total,
  capacity_booked,
  is_selectable,
  status
) VALUES (
  'abc123...', -- Your layout_id
  'STAGE',
  'Backstage Access',
  304.5,
  106.495,
  471,
  171,
  100,  -- ← Set real capacity
  0,
  true,
  'active'
);
```

### **10. Done! ✅**

Your app will now:
- Load the SVG from `event_layouts.svg_url`
- Find sections with matching `polygon_key`
- Use `bbox_x/y/width/height` for clickable overlays
- Handle clicks and show tickets

## 🎯 Figma Design Rules

For best results, follow these rules when designing in Figma:

### ✅ **DO:**
1. Use clear, UPPERCASE IDs for sections: `STAGE`, `MVP`, `VIP`
2. Keep section IDs simple (no special characters)
3. Use separate layers for each clickable section
4. Include visual elements (paths, shapes) inside each section group
5. Use distinct fill colors for easy identification

### ❌ **DON'T:**
1. Use generic names like `Group 1`, `Frame 2` for sections
2. Mix sections with container groups
3. Use spaces in section IDs (use `BACKSTAGE` not `BACK STAGE`)
4. Nest sections inside other sections
5. Leave sections without visual content

## 🔧 Troubleshooting

### **Issue: No sections detected**

**Solution:**
- Ensure your section groups have IDs in Figma
- Use UPPERCASE IDs (STAGE, MVP, VIP)
- Check that groups contain visual elements (paths, shapes)

### **Issue: Wrong bounding box**

**Solution:**
- Bounding boxes are calculated from path coordinates
- Ensure all visual elements are inside the section group
- Check for hidden or clipped elements outside visible area

### **Issue: SQL insert fails**

**Solution:**
- Verify `layout_id` exists in `event_layouts` table
- Check that `polygon_key` values are unique per layout
- Ensure `event_id` in `event_layouts` exists in `events` table

### **Issue: Sections not clickable in app**

**Solution:**
- Verify `polygon_key` in database exactly matches SVG section ID
- Check `bbox_x/y/width/height` are not zero or negative
- Ensure `is_selectable = true` in database
- Confirm `status = 'active'` in database

## 📱 App Integration

The app automatically handles transformed SVGs:

1. **Event Detail Page** (`app/events/[id].tsx`):
   - Checks `event.booking_type === 'layout'`
   - Navigates to venue layout page

2. **Venue Layout Page** (`app/booking/venue-layout/[id].tsx`):
   - Loads SVG from `event_layouts.svg_url`
   - Fetches sections from database
   - Matches `polygon_key` to section IDs
   - Uses `bbox_*` for overlay positioning

3. **Section Tickets Page** (`app/booking/section-tickets/[id].tsx`):
   - Shows tickets for selected section
   - Uses existing `TicketCard` component
   - Follows paid event purchase flow
