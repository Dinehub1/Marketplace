Each route from `docs/brand-site-redesign-plan.md` was requested against the live brand host.
`REAL` = a page with real content. `PLACEHOLDER` = the noindexed "still being prepared" page.
`missing` = 404 / error — the route does not exist.

## Summary

- Planned route slots: **203**
- Exist today as real pages: **114**
- Noindexed placeholder pages: **3**

The routes that exist are the generic app pages (`/about`, `/contact`, `/faq`, `/pricing`,
`/services`, `/login`) which the brand router already serves for every brand. What is missing
almost everywhere is the *brand-specific semantic* layer — `/doctors`, `/plumbers`, `/jobs`,
`/courses`, `/used-cars` — which is exactly the work the rollout has to build.
